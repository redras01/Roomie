# Dreamland

Plan a room on your phone, share it with a friend, and let them send their ideas back.

## Put it on GitHub Pages (free)

1. Create a GitHub account, then a **new public repository** (for example `dreamland`).
2. Upload every file in this folder, including the `icons` folder and `.nojekyll`.
3. Repository → **Settings → Pages** → Source: *Deploy from a branch* → branch `main`, folder `/ (root)` → Save.
4. After a minute your address appears, like `https://yourname.github.io/dreamland/`. Share that link.

Screens change now and then. If something looks different, check GitHub's Pages help.

## Updating without losing anyone's rooms

- Rooms are stored in each person's browser, under the site address. **Keep the address the same** (same GitHub username, no custom-domain switch) and updates never touch saved rooms.
- To update: upload the new files over the old ones (same names). Nothing else to do.
- Every update must keep reading older saves. Rooms are also copied to a second store in the browser (the vault) with automatic snapshots.

## Vault (More tab → Vault)

- **Save vault file**: downloads all rooms. This is the only copy that survives if the browser's data is cleared. Do it now and then.
- **Copy as code**: same, as text you can paste into Notes.
- **Snapshots**: automatic restore points, kept before deleting or importing. Restoring adds rooms back and never replaces what you have.
- If the browser loses its main storage but keeps the vault, the app offers to restore your rooms on the next visit.

## Friends

1. Rooms and views → **Share room** → send the link (or code or file).
2. The friend opens it and taps **Make my copy**. They can move things, add pieces and make new views. Their copy never changes yours.
3. They tap **Send back**, add their name, pick the views, and send you the link or code.
4. You open it. Tap **Add to my room** (their views appear as "Anna: View 1") or **Save as new room**. Your original is never replaced.

Nothing syncs live. Sharing happens by link, code or file.

## Install on a phone

- iPhone (Safari): open the address → Share → Add to Home Screen.
- Android (Chrome): menu ⋮ → Install app.
Adding it to the Home Screen also helps keep its storage from being cleared.
